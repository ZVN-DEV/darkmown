# Hello, Darkmown

This post is a plain `.md` file — strict CommonMark, **zero** framework
JavaScript. It loads instantly and is trivial to edit.

When I want something interactive — a like button, a live filter, a form — I
rename a file to `.wd` and add a directive. Static stays static; only the pages
that need it ship the tiny reactive runtime.
